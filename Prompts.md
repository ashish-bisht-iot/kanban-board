# Sprint 05 — Kanban Board Prompts.md

## Sprint Objective
Build a Trello-style Kanban Task Board in React.js using Vite.

## AI Prompts Used

### Phase 1 — Base MVP
- "Explain how React useState works for managing an array of tasks"
- "How do I pass a function as a prop from parent to child in React (lifting state up)?"
- "Build a 3-column Kanban board layout with To Do, In Progress, and Done using React and CSS Grid"

### Phase 2 — UI/UX Polish
- "How do I implement inline editing with a toggle state in React?"
- "Explain conditional CSS class rendering based on a priority field in React"
- "How does localStorage persist React state across hard refreshes using useEffect?"

### Phase 3 — Advanced
- "How does @dnd-kit/core work for drag-and-drop in React?"
- "Explain SortableContext and useSortable from @dnd-kit/sortable"
- "How do I implement real-time search filtering over a React state array?"

## Key React Concepts Learned
- useState for state arrays and objects
- useEffect for side effects (localStorage sync)
- useCallback for memoizing handlers
- Props drilling from App → Column → TaskCard
- Lifting state up (child → parent via function props)
- Controlled inputs
- Conditional rendering and CSS class application
- DnD with @dnd-kit (DndContext, useSortable, useDroppable)
